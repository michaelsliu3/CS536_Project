# Required report format

Michael supplied these NeurIPS 2026 LaTeX template files on October 31, 2026,
and selected them as the formatting reference for this project’s reports.
Agents preparing reports should read these files and use this style instead of
the IEEE defaults in the paper-writing skills.

- `neurips_2026/neurips_2026.tex`: example document and formatting instructions.
- `neurips_2026/neurips_2026.sty`: style package for layout, fonts, headings and title.
- `neurips_2026/checklist.tex`: conference reproducibility and research checklist;
  the example document includes it with `\input{checklist.tex}`.

These are unchanged reference copies, not a project report or verified results.
Keep the three files together when copying the template into a report project.
Write project content in a separate draft; preserve these originals.

Course requirements still govern submission length and content: the midpoint
check-in is at most 3 pages; the final report is 5–8 pages plus an unlimited
appendix, per the kickoff. The template’s conference nine-page limit,
submission/anonymity rules and checklist requirements do not automatically become
course requirements. Continue acknowledging tools and LLM assistance as the course
requires, even where the conference checklist is less strict.

Choose the appropriate author-visible mode for the course draft (for example,
`\usepackage[preprint]{neurips_2026}`), rather than implying NeurIPS acceptance or
submission. Do not change the style’s margins or fonts to squeeze in more text.
